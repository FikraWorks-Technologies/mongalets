# MongaLets Frontend Roadmap

## Phase 1 — Completed

- Public product homepage
- Role explanations and provider categories
- Role-aware authentication design
- Passwordless authentication modal
- Responsive portal shell
- Cross-tab session synchronization

## Phase 2 — Completed in version 0.2

- Full owner and facility-management dashboard pages
- Full tenant and resident dashboard pages
- Full service-provider dashboard pages
- Full guest dashboard pages
- Full platform-administrator dashboard pages
- Route-based navigation for every dashboard section
- Portfolio cards and data tables
- Request, job, quotation and integrity Kanban boards
- Role-aware calendars
- Finance and payment views
- Unified messaging interface
- Maps and arrival guidance
- FikraWorks BulkSMS campaign interface
- Reports, settings, detail modals and action flows
- Responsive desktop, tablet and mobile states

## Phase 3 — Backend and real workflows

- Production authentication and authorization
- Organization, property, building, floor and unit records
- Tenant, lease and guest records
- Real image, video and document storage
- Request creation and workflow state engine
- Provider assignment and quotation approval
- Before-and-after evidence and completion confirmation
- M-Pesa, bank and card payment integrations
- Real-time notifications and audit logs
- FikraWorks BulkSMS integration

## Phase 4 — Public listings and short stays

- Listing search and filters
- Property details
- Availability calendar
- Booking and payment flow
- Host listing management
- Guest checkout and review publication
- Cleaning and turnover operations
- Guest add-ons

## Phase 5 — Intelligence and ecosystem integrations

- ReviewsPro integration
- Ask Fundi property assistant
- Portfolio forecasting
- Provider matching intelligence
- Automated rent and booking communication
- Owner reports and scheduled exports
- Data Integrity Center automation
